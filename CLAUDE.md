# DuonDevKit — Coding Rules

## Comments
- Không viết comment thừa thãi (không giải thích lại điều code đã tự nói rõ).
- Khi cần comment, chỉ viết **summary ngắn gọn nhưng đầy đủ**: nêu đúng lý do/hành vi đặc biệt (why), không diễn giải dài dòng từng bước.
- Riêng code test (`*.Tests` projects): thoải mái hơn, được phép comment giải thích scenario/lý do test kỹ hơn nếu cần.
